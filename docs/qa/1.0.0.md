# Проверка 1.0.0

Дата: 14 ноября 2026. Окружение: MacBook на Apple M4 Max, macOS 15.7.9 (24G830), Xcode 26.3,
Swift 6.2.4. Раскладки: ABC и «Русская».

Документ разделяет три состояния: **проверено**, **реализовано без живой проверки** и
**известные ограничения**.

## Проверено автоматически

`./scripts/check.sh` — контрольные суммы словарей, поиск секретов, `swift-format --strict`, сборка с
`-warnings-as-errors`, 63 теста Swift Testing.

Не сконвертированные слова — настоящие совпадения с английскими: «руку» = `here`, «рук» = `her`,
«мы» = `vs`, «ли» = `kb`. Их исправляет двойной Shift, после двух раз — автоматически.

Тесты набирают текст через `TypingSimulator`: он подаёт в `TypingSession` физические клавиши и применяет
её ответы к строке-«документу». Это проверяет решения и арифметику замен, но не поведение чужих полей.

## Реализовано, живая проверка не проведена

Перехват клавиатуры, ввод исправлений в чужие поля, переключение системной раскладки, HUD в «чёлке»,
серый текст автодополнения у каретки и список вариантов требуют разрешения «Универсальный доступ»,
которое выдаёт только владелец. На момент записи оно не выдано, поэтому **в чужих приложениях не
проверено ничего**: ни Заметки, ни браузеры, ни мессенджеры.

Экраны приложения проверены по снимкам (`LangSwitch --snapshots`), в светлой и тёмной теме.

Что нужно проверить руками после выдачи разрешения, в тестовой заметке:

1. `ghbdtn` + пробел → «привет », раскладка переключилась, следующая буква русская.
2. Быстрый набор трёх слов подряд без пауз — нет потерянных и лишних символов.
3. Слово + Enter сразу — исправление успевает до перевода строки.
4. Backspace сразу после замены возвращает набранное; ⌘Z в Заметках ведёт себя ожидаемо.
5. Двойной Shift на слове, которого нет в словаре.
6. `figma`, `git`, ссылка, адрес почты — не меняются.
7. Автодополнение: серый текст у каретки, Tab принимает.
8. Двойной клик по слову — список вариантов, выбор цифрой и Enter.
9. То же в адресной строке Chrome/Safari и в поле Telegram.

## Известные ограничения

- Сборки подписаны ad hoc: без Developer ID и нотарификации Gatekeeper просит подтвердить запуск, а
  после обновления разрешение «Универсальный доступ» нужно выдать заново.
- Запятые ставятся по узкому набору правил. Тся/ться, не/ни, обособление оборотов и другие правила,
  зависящие от смысла, не реализованы.
- Синонимы — из встроенного тезауруса на 2 100 слов, составленного для проекта; форма синонима
  подбирается по окончанию и может не совпасть с формой исходного слова.
- Частотные списки и сленг составлены вручную, без корпуса; порядок частот приблизительный.
- Раскладки, отличные от русской и латинской, не участвуют. Украинская, болгарская и другие кириллические
  раскладки намеренно не считаются русскими.
- Автодополнение у каретки зависит от того, сообщает ли приложение её положение через Accessibility;
  иначе подсказка показывается в «чёлке».
