# Проверка 1.0.0

Дата: 14 ноября 2026. Окружение: MacBook на Apple M4 Max, macOS 15.7.9 (24G830), Xcode 26.3,
Swift 6.2.4. Раскладки: ABC и «Русская».

Документ разделяет три состояния: **проверено**, **реализовано без живой проверки** и
**известные ограничения**.

## Проверено автоматически

`./scripts/check.sh` — контрольные суммы словарей, поиск секретов, `swift-format --strict`, сборка с
`-warnings-as-errors`, 68 тестов Swift Testing.

| Проверка | Результат |
| --- | --- |
| Целые фразы: «Ghbdtn^ vtyz pjden Fyyf b z lbpfqyth d Vjcrdt!», «Z hf,jnf. d figma e;t 12 ktn» | Совпадают с ожидаемым и при наборе, и через команду «Исправить» |

| 120 правильных текстов (6 130 слов), набранных со всеми исправлениями | 0 изменений |
| Те же 120 текстов через команду «Исправить выделенное» | 0 изменений, кроме тире |

| Сленг и названия: кринж, имхо, фича, деплой, Zoltra, iPhone, SwiftUI | Не меняются |

Не сконвертированные слова — настоящие совпадения с английскими: «руку» = `here`, «рук» = `her`,
«мы» = `vs`, «ли» = `kb`. Их исправляет двойной Shift, после двух раз — автоматически.

Тесты набирают текст через `TypingSimulator`: он подаёт в `TypingSession` физические клавиши и применяет
её ответы к строке-«документу». Это проверяет решения и арифметику замен, но не поведение чужих полей.

## Живая проверка

14 ноября 2026, сборка с подписью Apple Development, разрешение «Универсальный доступ» выдано владельцем.

| Сценарий | Где | Результат |
| --- | --- | --- |
| `ghbdtn` + пробел при раскладке ABC | Заметки, тестовая заметка | «Привет », системная раскладка переключилась на русскую (3 прогона) |
| `ghbd` без пробела | Заметки | «прив» сразу после четвёртой буквы, раскладка русская (2 прогона) |
| Продолжение слова после ранней конвертации | Заметки | Следующие буквы приходят уже кириллицей |
| Опечатка «сдеаем», заглавная буква в начале предложения | Чат-приложение на Electron, набор владельца с физической клавиатуры | «сделаем», «Минимализм» |

Проверка в Заметках выполнялась синтетическими нажатиями инструмента управления экраном. Он надёжен
только для латинских букв при активной раскладке ABC: в остальных случаях его события несут не те коды
клавиш, и такие прогоны отброшены. Поэтому **не проверено вживую**: английский текст в русской раскладке,
Backspace-отмена, двойной Shift, автодополнение у каретки, список вариантов по двойному клику, поведение
в браузерах и мессенджерах, быстрый набор с физической клавиатуры и Enter сразу после слова. Эти сценарии
покрыты только `TypingSimulator`.

Найдено и исправлено по ходу проверки:

- разрешение отслеживалось только при открытом окне онбординга — перехват не запускался, если окно
  закрыли раньше;
- окно не меняло размер по высоте;
- пропущенная буква исправлялась только в 57 % случаев (теперь 84 % для русского, 89 % для английского
  на 1 300 частых словах; перестановка и удвоение — 99–100 %);
- слово не конвертировалось, пока не нажат пробел — добавлена ранняя конвертация после четырёх букв;
- слово не конвертировалось, если перед ним стёрли текст Backspace'ом дальше, чем видела программа
  (сценарий «набрал, стёр, набрал заново»): теперь раскладка исправляется и в этом случае, а положение
  каретки уточняется через Accessibility;
- конвертация в «мусор с пунктуацией» («кажде» → `rf;lt`), найденная тестом опечаток.

## Известные ограничения

- Сборки подписаны ad hoc: без Developer ID и нотарификации Gatekeeper просит подтвердить запуск, а
  после обновления разрешение «Универсальный доступ» нужно выдать заново.
- Запятые ставятся по узкому набору правил. Тся/ться, не/ни, обособление оборотов и другие правила,
  зависящие от смысла, не реализованы.
- Синонимы — из встроенного тезауруса на 2 100 слов, составленного для проекта; форма синонима
  подбирается по окончанию и может не совпасть с формой исходного слова.
- Частотные списки и сленг составлены вручную, без корпуса; порядок частот приблизительный.
- Раскладки, отличные от русской и латинской, не участвуют. Украинская, болгарская и другие кириллические
  раскладки намеренно не считаются русскими.
- Автодополнение у каретки зависит от того, сообщает ли приложение её положение через Accessibility;
  иначе подсказка показывается в «чёлке».
