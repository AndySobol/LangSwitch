# Проверка 1.3.0

Дата: 15 ноября 2026. Окружение: MacBook на Apple M4 Max, macOS 15.7.9, Swift 6.2.4.
Тема выпуска: обновления из приложения и автодополнение с учётом контекста. Движок исправлений не
менялся; его измерения — в [1.2.0.md](1.2.0.md).

## Проверено автоматически

`./scripts/check.sh` — 108 тестов, линт, сборка с `-warnings-as-errors`: зелёные.

### Автодополнение

1 500 русских и 1 500 английских предложений, не входивших в модель контекста. Для каждого слова от пяти
букв проверяется подсказка после третьей и каждой следующей буквы. «Экономия» — доля нажатий, которых
не пришлось бы делать, принимая первую верную подсказку клавишей Tab.

| Измерение | Русский: было → стало | Английский: было → стало |
| --- | --- | --- |
| Показанная подсказка — именно то слово | 34 % → **79 %** | 49 % → **86 %** |
| Слов, для которых появилась верная подсказка | 16 % → **26 %** | 16 % → **22 %** |
| Экономия нажатий | 4,8 % → **11,2 %** | 5,2 % → **9,4 %** |
| То же без предыдущего слова | 72 %, 4,3 % | 78 %, 5,2 % |

Следующее слово до первой буквы: предлагается в 2,6 % (RU) и 2,4 % (EN) позиций, верно в 76 % и 71 %.

Оговорка: предложения взяты из того же собрания, на котором считалась модель контекста (хотя сами в неё
не входили). На вашем собственном тексте цифры будут ниже, пока приложение не накопит ваши пары слов.

### Обновления: разбор ленты

Тесты `UpdateTests`: порядок версий (`1.10.0` новее `1.2.1`, `v1.2` = `1.2.0`, `1.2.0-beta.3` = `1.2.0`),
чтение ленты Atom, отбор версий новее текущей, чтение суммы из `SHA256SUMS.txt`, отказ на непонятном
ответе, отказ на теге, который не является простым номером версии (`v2.0/../../evil`).

Загрузка словарей и моделей при запуске — 0,9 с в выпускной сборке (индекс автодополнения по всему
списку добавил около 0,3 с); обработка границы слова в отладочной сборке — в среднем 2,0 мс.

## Проверено вживую, без интерфейса

Команды из `CONTRIBUTING.md`, настоящая страница выпусков, настоящий выпуск 1.2.0.

| Проверка | Результат |
| --- | --- |
| Сборка, считающая себя 1.0.0, читает ленту | находит 1.2.0; тег `v1.1.0` без файлов пропущен |
| Сборка, считающая себя 1.2.0 | «последняя версия» |
| Загрузка образа и сверка SHA-256 | образ 1.2.0 скачан, сумма совпала |
| Установка поверх копии с ожиданием другой версии | отказ «не та программа или версия», копия не тронута |
| Установка в папку только для чтения | отказ «не удалось заменить», копия не тронута |
| Установка поверх копии | копия стала 1.2.0, подпись цела, образ отмонтирован, временных файлов нет |
| Полный путь: копия 1.3.0 под видом 1.0.0 обновляет саму себя | заменила себя на 1.2.0 и запустила новую версию из той же папки |
| Данные пользователя после испытаний | `learning.json` читается, словарь и наблюдения на месте |

Попутно найдено и учтено: JSON API GitHub отвечает 403 при исчерпании квоты (60 запросов в час на
IP-адрес без авторизации), и в день проверки квота этого адреса была исчерпана. Поэтому источником
выбрана лента Atom, у которой квоты нет.

## Реализовано без живой проверки

- **Кнопки в настройках и в меню.** Состояния «проверяю → есть обновление → скачиваю → устанавливаю»
  пройдены теми же вызовами, что и кнопки, но сами кнопки мышью не нажимались. Экран проверен по снимку.
- **Обновление настоящей установленной копии до следующей версии.** Проверялась копия во временной
  папке. Первое настоящее обновление случится, когда выйдет версия после 1.3.0.
- **Автоматическая проверка раз в сутки** и уведомление в «чёлке» — логика общая с ручной проверкой, но
  суток ожидания в проверке не было.
- **Живой набор в приложениях** для этой сборки не повторялся.

## Известные ограничения

- **После обновления macOS заново просит «Универсальный доступ».** Выпуски подписаны ad hoc, а система
  привязывает разрешение к подписи. Пока разрешение не выдано, исправления не работают; приложение
  показывает это и ведёт в настройки. Уйдёт только с подписью Developer ID.
- **Подлинность выпуска равна подлинности страницы на GitHub.** Сумма и подпись защищают от повреждения
  и подмены в пути, но не от компрометации самого репозитория.
- **Обновление — только на последнюю версию и только целиком** (образ около 9 МБ); отката на прежнюю
  версию из приложения нет.
- **Локальная сборка с сертификатом разработки** после обновления заменяется выпуском с подписью ad hoc.
- **Автодополнение знает одно предыдущее слово.** Имена и грубые слова не предлагаются, даже если вы их
  часто пишете, — пока они не попадут в личный словарь.
- Ограничения движка исправлений — в [1.2.0.md](1.2.0.md).
