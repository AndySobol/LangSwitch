# Безопасность

LangSwitch видит нажатия клавиш во всех приложениях — иначе исправлять раскладку на лету невозможно.
Поэтому модель безопасности описана здесь явно.

## Что приложение делает и чего не делает

- Ваш набор не покидает Mac. Телеметрии нет. Единственное обращение в сеть — проверка и загрузка
  обновлений со страницы выпусков этого репозитория; оно отключается в настройках и описано в
  [docs/PRIVACY.md](docs/PRIVACY.md).
- Хранит в памяти только текущее слово и несколько предыдущих — пока вы печатаете в одном поле.
  Клик мышью, переход в другое окно или сочетание клавиш стирают это состояние.
- Не видит пароли: при защищённом вводе (поля паролей, Secure Keyboard Entry в терминале) macOS не
  передаёт нажатия ни одной программе.
- На диск пишет только то, что описано в [docs/PRIVACY.md](docs/PRIVACY.md): настройки, счётчики,
  личный словарь. Сбор фраз для тренажёра выключен по умолчанию.
- Файлы данных лежат в `~/Library/Application Support/LangSwitch` с правами только для владельца.

## Сообщить об уязвимости

Напишите через [приватное уведомление GitHub](https://github.com/AndySobol/LangSwitch/security/advisories/new).
Пожалуйста, не публикуйте детали в открытых задачах до исправления. Ответ — в течение недели.

## Проверка сборки

Релизы собираются в GitHub Actions из тега. К каждому релизу приложен `SHA256SUMS.txt`. Сборки пока
подписаны ad hoc (без Developer ID и нотарификации), поэтому Gatekeeper попросит подтвердить запуск.
Тем, кому это не подходит, проще собрать приложение из исходников: `./scripts/build.sh`.

## Обновление из приложения

Встроенное обновление принимает файлы только по адресам `https://github.com/AndySobol/LangSwitch/releases/…`,
сверяет образ с `SHA256SUMS.txt` того же выпуска, а приложение в образе — с идентификатором пакета,
номером версии и `codesign --verify`. Это защищает от повреждённой или подменённой в пути загрузки, но
не от компрометации самого репозитория: пока сборки не подписаны Developer ID, подлинность выпуска
равна подлинности страницы на GitHub. Из-за подписи ad hoc macOS после обновления заново спрашивает
разрешение «Универсальный доступ».
